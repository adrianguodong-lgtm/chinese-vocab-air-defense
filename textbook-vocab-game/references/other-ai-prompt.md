# 给其他 AI 的修改提示

将 assets/game-template.html（或已生成的单文件 HTML）、词汇表截图、配套录音交给支持文件和音频处理的 AI，并附上以下提示：

> 请把这份 HTML 更新为截图中的本课词汇游戏。只提取独立列出的生词及旁注词汇，排除课文例句；统一简体、去除括注及拼音词性释义；全局去重并按最长优先删除被其他词条包含的短词，按首次出现顺序排列。为每个保留词配正确拼音和英文释义，从录音中定位并切出完整原声，不含报数、邻词。没有录音时使用可用的系统中文语音生成发音，并标明系统合成。把全部 MP3 用 Base64 data URI 内嵌。严格只替换 WORDS、WORD_EN、WORD_AUDIO 三张数据表，三表之外的 HTML/CSS/JS 逐字保持一致，不修改游戏逻辑、界面、关卡和音效。文件名按本次截图的课号、课文标题、生词组号命名，缺失信息不猜测。交付完整的单文件 HTML，不仅给修改建议或代码片段。找不到目标词发音、无法识别词条或工具无法处理音频时先说明，不虚构时间戳或错贴原声。

可单独使用此 HTML；它不依赖 Skill、Python 或 Codex 才能运行。此提示和 Skill 并不赋予其他模型本来没有的转写、切音频或文件导出能力。
