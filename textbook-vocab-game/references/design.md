# 中文词汇识记游戏——防空战（词汇可替换）

开发者：微信公众号“洞观中文”。

## 它做什么

| 项目 | 说明 |
| --- | --- |
| 游戏形态 | 单文件 HTML，打字 / 朗读闯关，共 4 关 |
| 训练维度 | 听、识、读、写（电写） |
| 技能做的事 | 把教材某一课的**生词 + 教材原声**注入游戏模板，产出一份新的单文件 HTML |
| 不变的东西 | 游戏逻辑一行不动，只替换 `WORDS` / `WORD_EN` / `WORD_AUDIO` 三张表 |

## 四关结构

| 关卡 | 屏幕呈现 | 学生产出 | 考察 |
| --- | --- | --- | --- |
| 1 | 汉字 + 拼音 | 打字 | 听辨、识字、写字（电写） |
| 2 | 仅汉字 | 打字 | 识字、拼音、打字（电写） |
| 3 | 汉字 + 拼音 | 读词 | 识字、拼音识读、说（发音） |
| 4 | 仅汉字 | 读词 | 识字、发音 |

适合国际学校、海外中文课堂、对外汉语教师。只要教材有配套录音、有生词表，就能用；也可以用自己的生词表和词汇录音。没有录音时使用系统自带的中文发音，导出后嵌入 HTML。

“电写”指通过键盘输入汉字或拼音，并非手写笔画训练。键盘输入和内嵌音频可离线使用；语音识别关卡需要浏览器支持及麦克风授权，部分实现需要联网。

模板只是独立的 HTML 文件，不依赖 Codex 才能打开。Skill 是将截图和录音转换为新课游戏的工作流程；教学说明不会自动追加进学生游戏界面。
